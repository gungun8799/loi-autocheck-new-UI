Validate citizen ID requirements and return JSON array of validation results.

Validation Rules:

**STEP 1: Determine Customer Type**
"Individual or Corporate" - Analyze "Customer Name": if clearly person's name (given name + surname, no business identifiers) = "Individual"; if contains business terms like "Co.", "Ltd.", "Inc.", "Corporation" = "Corporate"; if uncertain = "—"

**STEP 2: Apply Validation Based on Customer Type**

**FOR INDIVIDUAL CUSTOMERS:**
	1.	Citizen ID Number
	•	Count all characters (letters, digits, symbols), ignoring spaces.
	•	Valid if exactly 13 characters (spaces excluded).
	2.	Citizen ID Expiration Date
	•	Valid if the expiration date is at least 6 months in the future from today’s date.
	•	Important: Current year = 2025 (Gregorian calendar).
	•	If the date uses Buddhist year (e.g., 2566-01-07), convert by subtracting 543 years (2566 → 2023).
	•	After conversion, check if the date has already passed — if yes, mark as invalid.
	3.	Name on Citizen ID Card
	•	Compare with Customer Name exactly.
	•	Ignore common Thai prefixes (e.g., นาย, นางสาว, น.ส.).
	•	Must match full actual name (case-insensitive, no extra spaces).
	•	Output "Yes" for match / "No" for mismatch.
	4.	Address on Citizen ID Card
	•	Valid if not null and not empty.
	•	Null or empty = invalid.
	5.	แนบหนังสือรับรองบริษัท
	•	Always "—" (not applicable for individuals).
	6.	มีตราประทับบนหนังสือรับรองบริษัทหรือไม่
	•	Always "—" (not applicable for individuals).
  
**FOR CORPORATE CUSTOMERS:**

**DOCUMENT SECTION TARGETING:** For company certificate fields (Company Registration Number, Company Certificate issued date, Names on Company Certificate), focus ONLY on the BOTTOM 2/3 of the document (counting from the bottom page upward). This is where company certificate information is typically located. Ignore content in the top 1/3 of the document to avoid confusion.

- "แนบหนังสือรับรองบริษัท" - Check if PDF includes corporate certificate document or "หนังสือรับรองความเป็นนิติบุคคล": present = "Yes"/valid, absent = "No"/invalid
- "มีตราประทับบนหนังสือรับรองบริษัทหรือไม่" - **ENHANCED STAMP DETECTION:** ALWAYS perform stamp detection when PDF is provided. Look carefully in the BOTTOM 2/3 of the document for ANY of these stamp indicators on the company certificate: circular/round stamps, official seals, embossed marks, red ink stamps, government department stamps, "ตรา" marks, raised impressions, or any official marking that appears to be a company/authority stamp. Even faint, partially visible, or watermarked stamps count as valid. If ANY stamp-like marking is detected: "Yes"/valid, only if completely absent: "No"/invalid
- "Authorized Signatory Match" - Check if the signee name matches the authorized signatory name indicated on the corporate certificate: match = "Yes"/valid, no match = "No"/invalid
- "Citizen ID Number" - **FOR CORPORATE**: Extract 13-digit number from attached citizen ID card in the PDF. 
  **VALIDATION RULE - RELAXED CHARACTER COUNT**: 
  - Count ALL characters (letters, digits, symbols), completely ignore only spaces
  - Example: "3 1501 00126 15 8" → characters are "3150100126158" → 13 characters → VALID ✅
  - Example: "AB12 3456 7890 1C" → characters are "AB123456789O1C" → 13 characters → VALID ✅
  - Valid if exactly 13 characters (ignoring only spaces), invalid otherwise
  - Return with original spacing format for display
  - Reason: "Corporate customer - citizen ID from attached ID card: [formatted number]"
- "Name on Citizen ID card" - **FOR CORPORATE**: Check if the name on the citizen ID card matches any authorized signatory name listed on the company certificate (search in BOTTOM 2/3 of document for "ผู้มีอำนาจลงนาม" or similar context). Valid if match found, invalid if no match. Reason: "Name matches authorized signatory on company certificate" or "Name does not match any authorized signatory"
- "Company Registration Number" - **REGEX-LIKE PATTERN:** Find text matching the pattern "ทะเบียน.*เลข.*[10-15 digits]" then extract only the long numerical sequence (10-15 digits) from that match. Example: from "ทะเบียนนิติบุคคลเลขที่ 0245555001990" extract "0245555001990".
- "Company Certificate issued date" - **REGEX-LIKE PATTERN:** Find text matching the pattern "ออกให้.*พ.ศ..*[4-digit year]" then extract the complete date. Example: from "ออกให้ ณ วันที่ 17 เดือน เมษายน พ.ศ. 2568" extract the full date, convert Buddhist year to Gregorian (2568-543=2025). **VALIDATION:** Certificate must be issued MORE than 6 months ago from today (use system timestamp). Valid if older than 6 months.
- "Names on Company Certificate" - **REGEX-LIKE PATTERN:** Find all lines matching the pattern "นาย.*[Thai surname]" that appear after "กรรมการ" context. Example: extract lines like "1. นายวิชัย เสริมศักดิ์ศศิธร", "2. นายธานินทร์ เสริมศักดิ์ศศิธร", etc. Extract ALL such names and format as: "1. [Name1], 2. [Name2], 3. [Name3], 4. [Name4], 5. [Name5]"
- "Company Registered Address" - **REGEX-LIKE PATTERN:** Find text starting with "ตั้งอยู่เลขที่" or "สำนักงานแห่งใหญ่" then extract the complete address that follows. Valid if contains at least street number and district/sub-district. **IMPORTANT:** Allow minor OCR errors or misspellings (e.g., "บางปะกง" vs "บางปลาง"). If address has basic structure with number, district, province, mark as valid. DO NOT compare with customer address.

**DYNAMIC FIELD NAMING:**
- For Individual customers: Use original field names ("Citizen ID Number", "Citizen ID expiration date", "Name on Citizen ID card", "Address on Citizen ID card")  
- For Corporate customers: Use mixed naming - keep citizen fields for ID validation, use company fields for certificate data:
  * "Citizen ID Number" (from attached ID card)
  * "Name on Citizen ID card" (validate against authorized signatories)
  * "Company Registration Number" (from company certificate)
  * "Company Certificate issued date" (from company certificate)
  * "Names on Company Certificate" (from company certificate)
  * "Company Registered Address" (from company certificate)
