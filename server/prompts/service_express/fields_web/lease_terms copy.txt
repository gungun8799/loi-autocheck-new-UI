Extract lease terms for SERVICE EXPRESS contracts from WEB scraped data and return as a complete JSON object with ALL required fields listed below.

**INTELLIGENT YEAR ALLOCATION LOGIC FOR WEB SOURCES:**
- Use "Proposed lease commencement date" and "Proposed lease expiry date" to calculate total duration
- Divide total lease duration into equal 1-year periods
- Calculate year boundaries intelligently:
  * Year 1: Start = Proposed commencement date, End = Start date + 11 months + 30 days
  * Year 2: Start = Year 1 End date + 1 day, End = Start date + 11 months + 30 days  
  * Year 3: Start = Year 2 End date + 1 day, End = Proposed expiry date (or calculated)

**DYNAMIC YEAR INCLUSION:**
- Only include years that actually exist in the contract duration
- If lease is 2 years total, only show Year 1 and Year 2
- If lease is 1 year total, only show Year 1
- Do NOT include Year 3 unless contract actually spans 3+ years

"Lease Type" - **SERVICE EXPRESS CONTRACT**: Always return "Service Express" for service express contracts

1. **PRIMARY PATTERN**: Look for "LEASE PROPERTY TAX:" followed by the actual value in the data
2. **SECONDARY PATTERN**: Look for "Lease Property Tax" fields in rental schedule or terms section
3. **VALUE EXTRACTION**: 
   - Extract the exact value as shown in the data (e.g., "PTS - PT Standard", "PT Mall", "10.00", "12.50")
   - If the field is empty or not found, return null
   - Do NOT convert text values to numbers unless the data itself shows a number
4. **FORMAT**: Return exactly as shown in the source data

"Monthly charge" - **WEB EXTRACTION PATTERNS:**
1. **PRIMARY PATTERN**: Look for "Monthly Charges:" followed by "Yes" or "No"
2. **CONTEXT**: Usually appears near monthly charges configuration
3. **LOGIC**: If monthly charges are configured/enabled in web interface → "Yes", otherwise → "No"
