Extract service charge information and return in JSON format.

**WEB EXTRACTION PATTERNS:**
Extract data from HTML form fields, table cells, and structured web elements.

**IMPORTANT:** For PDF data, look for Thai text patterns. Common area service charges appear as "ค่าบริการพิเศษสำหรับไอเย็น" or "ค่าบริการพิเศษสําหรับไอเย็นและไฟฟ้า(พื้นที่ส่วนกลาง)" with amounts like "เดือนละ 5,880.00 บาท" and date ranges like "ตั้งแต่วันที่ 01 กรกฎาคม 2568 จนถึงวันที่ 30 มิถุนายน 2570".

**CRITICAL MAPPING RULES:**
- "Common Area Cool Air Service Fee" → Map to "Common area" fields, NOT "in the renting space" fields

- If only "Common Area Cool Air Service Fee" exists, all "in the renting space" fields should be NULL
- **IMPORTANT:** If "Other service charge before tax (in the renting space)" is "0" or "0.00", then ALL of the following fields MUST return null/empty:
  - "Other service charge (in the renting space) Charge description"
  - "Other service charge (in the renting space) start date"
  - "Other service charge (in the renting space) end date"
  - "Other service charge before tax (Common area)"

**PDF PATTERNS:** Look for "ค่าบริการพิเศษ" entries that contain keywords indicating renting space: "ภายในสถานที่เช่า", "ในสถานที่เช่า", "สถานที่เช่า" or similar. Extract the amount after "เดือนละ" and before "บาท". If no renting space specific charge found, return 0.00.

**PDF PATTERNS:** For charges identified as renting space charges (containing "ภายในสถานที่เช่า" or similar), extract the descriptive text between "ค่าบริการพิเศษ" and "เดือนละ". Clean up line breaks and extra spaces. Include Thai text in parentheses like "สําหรับไอเย็น". If no renting space charge exists or amount is "0"/"0.00", return null.
